# Alternatly

**Alternatly** is a mobile app built with **React Native** and **Expo**, designed for people who love alternative fashion (goth, grunge, punk, and more) to buy, sell, and trade unique clothing items — a Vinted alternative for alternative fashion enthusiasts.  

---

## Features

- Browse, search, and filter clothing items by style and category  
- Create listings with photos, descriptions, and pricing  
- User authentication and profile management  
- Chat with sellers/buyers in-app  
- Favorite items and manage a wishlist
